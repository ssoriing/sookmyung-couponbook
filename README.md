# 숙명여대 쿠폰북

숙명여대 학생회 제휴 쿠폰을 모바일에서 관리하고 QR로 사용하는 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 주소를 열면 됩니다.

## 주요 기능

- 학번 입력 및 기기별 개인 쿠폰함
- 포라임 / 탕화쿵푸 초기 쿠폰 시드
- 쿠폰 사용 확인 모달
- 사용 쿠폰 localStorage 저장 및 즉시 제거
- 매장 QR 카메라 스캔 (`html5-qrcode`)
- 카메라 권한이 없을 때 매장 코드 직접 입력
- 숙명여대 인근 제휴 매장 커스텀 지도 + 말풍선 마커
- 모바일 하단 3탭 네비게이션

## 테스트 QR 코드

- 포라임: `S2026-FORAIM`
- 탕화쿵푸: `S2026-TANGHWA`

실제 서비스에서는 이 문자열을 실제 매장 QR에 넣고, 서버에서 쿠폰 사용을 검증하는 구조로 교체해야 합니다.
